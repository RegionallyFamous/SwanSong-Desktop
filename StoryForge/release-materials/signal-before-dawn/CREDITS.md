# Credits

## Signal Before Dawn

- Created and released by Nick Hamze / Regionally Famous. Repository commit
  authorship is recorded under Nick Hamze.
- Story, dialogue, characters, tracker score, sound effects, art direction,
  runtime adaptation, and release preparation were produced for this original
  homebrew project.
- Visual source development used imagegen-assisted PNGs followed by
  deterministic project scripts for cropping, chroma keying, palette
  reduction, sprite animation frames, review sheets, and release lettering.
  The evidence does not record a model name or version, so none is claimed.
- The eight original tracker cues share the radio's D-F-A signal motif. Their
  editable note data is stored in the packaged project JSON.
