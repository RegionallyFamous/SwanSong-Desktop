# Signal Before Dawn Soundtrack

These eight original tracker cues use the radio's D-F-A three-note signal as a
shared motif. The WAV files are two-loop desktop auditions of the editable
legacy tracker data in `projects/signal-before-dawn-slice.wscvn.json`.

| File | Cue | Story use |
| --- | --- | --- |
| `01-dead_air.wav` | Dead Air | Title and empty night watch |
| `02-three_notes.wav` | Three Notes | The radio first answers |
| `03-below_the_light.wav` | Below the Light | Investigation and linked clues |
| `04-answer_together.wav` | Answer Together | Trust route resolution |
| `05-blue_lens.wav` | Blue Lens | Beacon route resolution |
| `06-hidden_room.wav` | Hidden Room | Hatch discovery |
| `07-far_reply.wav` | Far Reply | Distant contact |
| `08-first_gull.wav` | First Gull | Sunrise coda |

`00-dead_air-emulator-proof.wav` is a two-loop recording from the compiled ROM
through Mednafen, not the desktop renderer. Its project, ROM, duration, levels,
and SHA-256 are bound by
`assets/signal-before-dawn-slice/emulator-audio-proof-report.json`.
