# Pocket Harbor

`Pocket Harbor` is a short original WonderSwan Color visual novel about two
collectors, Ren and Mina, hunting for a small, meaningful game on a rainy shop
day.

Build from the Story Forge root:

```bash
python3 scripts/build_wscvn_game.py pocket-harbor
```

Package and share:

```bash
python3 scripts/ship_wscvn_game.py pocket-harbor
```

Manual fallback after a fresh build:

```bash
python3 scripts/package_wscvn_game.py pocket-harbor
python3 scripts/verify_wscvn_game_release.py pocket-harbor
```

The source sheets live in `assets/sources/`; generated WSC-safe runtime assets
and the contact sheet are regenerated by `build_pocket_harbor.py`.
