## SwanSong 0.9.1 — A Better Welcome

SwanSong 0.9.1 makes the first launch clearer, the everyday language
friendlier, and help easier to find.

Expected app identity: **SwanSong 0.9.1 (19)**.

This is the current stable release for supported Apple silicon and Intel Macs.

## Start with the good part

New players now meet a short Start Here guide built around three useful
actions: add a game, press Play, and save or rewind whenever they like. It
explains the default keyboard controls, keeps advanced workbenches out of the
way, and can be reopened from the Help menu.

Returning players can open a concise What’s New story from Help. SwanSong
remembers the release story it has already shown, while Safe Mode, direct game
opens, and automated launches remain uninterrupted.

## Clearer words throughout the app

- Library, Homebrew, Translation Shelf, Time Ribbon, save-state timeline,
  Story Forge, Settings, and recovery screens now use shorter, more helpful
  language.
- Translation Shelf distinguishes a verified package from trust in the person
  or site that supplied it.
- Rewind and save-state actions describe what happens to the game and how Undo
  protects the current moment.
- About, privacy, support, FAQ, and release materials now tell the same
  player-first story.

## Install the release

Existing users can choose **SwanSong > Check for Updates…** on the default
stable channel. A manual install can download
`SwanSong-0.9.1-macOS-universal.zip` from the GitHub release and verify it
with `SHA256SUMS.txt` and `SwanSong-0.9.1-release.json`.

SwanSong requires macOS 14 or newer. It includes no games, translations, or
original system firmware. Use only software and hardware you own or are
authorized to use.
