A safer way to prepare your Analogue Pocket.

SwanSong 0.9.2 makes Pocket card setup clearer, more private, and harder to get wrong.

  • Check the card first. See its layout, installed Core version, game count, and anything that needs attention.
  • Take the right action. SwanSong offers install, update, verify, or repair based on what it finds.
  • Keep support private. Copy a useful card summary without names, paths, device identifiers, games, or save data.
  • Avoid the wrong release. Unrelated downloads and automatic Core downgrades are blocked.

SwanSong 0.9.2 is the current stable release. It is offered on the default update channel.

The separate SwanSong Core still requires its own authorized, hardware-qualified public release. Read the full release notes.
