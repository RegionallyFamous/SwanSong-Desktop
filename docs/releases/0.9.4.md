## SwanSong 0.9.4 — The Forge Comes Home

SwanSong 0.9.4 brings Story Forge's trusted writing framework into the signed
Mac app and gives the complete workshop one inspectable source home.

Expected app identity: **SwanSong 0.9.4 (22)**.

This is the current stable release for supported Apple silicon and Intel Macs.

## Open the Forge and start writing

Story Forge now resolves its fixed, hash-verified schema-v3 framework directly
from SwanSong. You can create, reopen, revise, and carry a story into Studio
without maintaining a separate framework checkout.

The complete authored workshop now lives under `StoryForge/` in the SwanSong
source repository. The signed app carries only the small reusable writing
framework—not the repository's games, manuscripts, art library, reader notes,
ROMs, or release archives.

## Keep human judgment human

Story Forge's proposal rooms, reader packets, art reviews, music reviews,
rights lane, and release gates remain evidence tools. SwanSong does not invent
a reader, approve its own prose, grant distribution rights, or turn an emulator
run into physical-hardware approval. Candidates with pending human or hardware
checks remain visibly blocked.

## Strengthen private source proof

Translation Lab can now authenticate the exact Original frame before private
source-provenance work begins. Its advanced tools can trace one bounded data
producer and represent an honest multi-rectangle source context without
returning game bytes, screenshots, private coordinates, or project paths.

These are optional Developer Tools. Everyday play, Start Here, the private
library, Time Ribbon, visual save states, Translation Shelf, Pocket setup, Safe
Mode, and privacy-safe support remain unchanged.

## Install the release

Existing users can choose **SwanSong > Check for Updates…** on the default
stable channel. A manual install can download
`SwanSong-0.9.4-macOS-universal.zip` from the GitHub release and verify it with
`SHA256SUMS.txt` and `SwanSong-0.9.4-release.json`.

SwanSong requires macOS 14 or newer. It includes no games, translations, save
data, manuscripts, or original system firmware. Use only software, hardware,
and source material you own or are authorized to use.
