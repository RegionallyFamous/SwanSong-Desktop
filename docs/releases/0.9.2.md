## SwanSong 0.9.2 — A Safer Pocket Setup

SwanSong 0.9.2 makes preparing an Analogue Pocket card clearer, more private,
and harder to get wrong.

Expected app identity: **SwanSong 0.9.2 (20)**.

This is the current stable release for supported Apple silicon and Intel Macs.

## Know what is on the card

The Analogue Pocket page can now check a selected SD card and explain its
layout, installed SwanSong Core version, WonderSwan game count, legacy folders,
and anything that needs attention. Its copyable support summary deliberately
omits the card name, path, device identifier, game names, and save data.

## Install with the right action

- SwanSong now offers the action that fits the card: first install, update,
  verify an already-current install, or repair damaged or missing Core files.
- Every successful action ends with short, exact next steps for safely
  ejecting the card and opening the Core on Pocket.
- Automatic downgrades and replacement of a development Core are blocked.
- The selected card is checked again before and after the download so swapping
  or changing it cannot bypass those protections.

## Find only real Core releases

SwanSong Core releases now have their own strict `core-vX.Y.Z` namespace.
Other projects published from the same repository—including homebrew—are
ignored instead of appearing as broken Core updates.

The separate FPGA project still owns its licensing, build, and physical Pocket
and Dock qualification. Until it publishes an authorized stable Core release,
SwanSong’s installer remains safely locked.

## Install the release

Existing users can choose **SwanSong > Check for Updates…** on the default
stable channel. A manual install can download
`SwanSong-0.9.2-macOS-universal.zip` from the GitHub release and verify it
with `SHA256SUMS.txt` and `SwanSong-0.9.2-release.json`.

SwanSong requires macOS 14 or newer. It includes no games, translations, or
original system firmware. Use only software and hardware you own or are
authorized to use.
