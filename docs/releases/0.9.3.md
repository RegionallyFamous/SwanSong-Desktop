## SwanSong 0.9.3 — Keep the Proof Moving

SwanSong 0.9.3 removes two runtime dead ends from long-form translation
verification while keeping game-derived captures, audio, and save data private.

Expected app identity: **SwanSong 0.9.3 (21)**.

This is the current stable release for supported Apple silicon and Intel Macs.

## Keep the end of a long route

Deterministic capture plans now retain the final 30 emulated frames of audio
for both Original and Patched during their existing replays. The WAV artifacts
are bound to the same route, ROM, engine, clock, and final frame as the visual
evidence, so a long route does not need to be replayed just to close its audio
check.

## Carry an exact save into LOAD and CONTINUE

- SwanSong can seal an authenticated Patched capture into two byte-identical
  private clones of the complete cartridge-owned persistence state.
- LOAD and CONTINUE consume their own clone in separate clean-power runs, with
  persistence staged before the ROM loads and no save-state restore.
- Each consumer retains a private final native frame and final audio window.
  The returned receipt contains only hashes, counts, booleans, and opaque
  identities—never paths, save bytes, screenshots, audio, or game text.
- Existing authenticated legacy capture pairs remain accepted for sealing, so
  completed evidence does not need an unnecessary replay.

## Exact evidence remains exact

Authorized capture graphs now include the two retained WAV roles and bind
their window, format, sample counts, and digests. The expanded public and
commercial pair, report, and graph schemas have new versions so older receipts
cannot be mistaken for the new contract.

These are Developer Tools for translation verification. They do not translate
a game automatically, publish private evidence, or replace whole-game review.
SwanSong remains the sole runtime authority for the resulting routes and
captures.

## Install the release

Existing users can choose **SwanSong > Check for Updates…** on the default
stable channel. A manual install can download
`SwanSong-0.9.3-macOS-universal.zip` from the GitHub release and verify it
with `SHA256SUMS.txt` and `SwanSong-0.9.3-release.json`.

SwanSong requires macOS 14 or newer. It includes no games, translations, save
data, or original system firmware. Use only software and hardware you own or
are authorized to use.
